# N1, amendment 2: controls, typing in VR, an address

Dated 2026-10-24, after the first build of the room (e2486d0) and before any of the code
below exists. Reason: dhilipsiva asked for keyboard and mouse controls, detected rather than
assumed, with VR as the fallback; the third reader found the Quest browser has no DOM overlay
inside an immersive session, so the room's form would vanish there; and the plan ratified
GitHub Pages as the public address. The original `N1.md` stands; this adds to it.

## Added to the test

1. **Input detection.** On load the page detects keyboard, pointer, touch, gamepad and XR
   controllers and shows a legend naming only what exists. Keyboard: arrows and WASD walk, Q
   and E turn, Shift runs, Enter focuses the question box, Escape returns to the room. Mouse:
   drag to look, wheel to move toward or away from Nell, click Nell to focus the box. Touch:
   one finger to look, two to move, a tap on Nell to ask. Gamepad: left stick walk, right
   stick look. XR: left thumbstick walk, right thumbstick snap-turn, trigger on Nell to ask.
   Movement is bounded to the room; the camera stays at eye height.
2. **Typing in VR.** Pointing at Nell and pressing the trigger (or pinching) focuses the
   question input so the headset's system keyboard opens; the answer is drawn on the board.
   `isSystemKeyboardSupported` is logged. Hand tracking is requested as optional.
3. **The address.** A Pages workflow publishes, on pushes to `main`, only `nell/` without its
   tests, the two memory files, `WAKE.md` and `README.md`, after the Node standing test passes.
   The branch `todo/N1` is allowed in the Pages environment for the device test before merge.
4. **The pin test.** A test in CI fails when the vendored engine build's recorded Nibli
   revision differs from the revision `Cargo.toml` pins.
5. **N2a folded in.** Nell's spoken line is the engine's English rendering of the question
   with the verdict; the proof stays below. No model.

memory if the browser exposes it. A screenshot or recording of the room. Compare the verdicts

## Evidence, falsifier, anti-fake, position, welfare, undo, done when

As in `N1.md`, with these additions: the legend must list no control the device lacks; the
same query typed on the desktop and on the Quest must give the same verdict and proof text;
the Pages deploy must be the commit the test used. Welfare unchanged: none. Undo: delete the
page, the workflow and the vendored builds. *Done when:* on the Quest the page enters VR,
Nell shows the standing lines TRUE from the on-device engine, and a query typed through the
system keyboard is answered with its verdict and proof; and on the desktop browser the same
with keyboard and mouse.
