# N8c1 — local Words and portable room conversations

Pre-registered 2026-10-26 before todo/N8c1. Implements the approved Talk and
export/import plan. Existing Candle Qwen3 CPU inference is reused; neural
embeddings, natural-language formalization, hosted providers and training stay
outside this slice. On 2026-10-26 the user additionally authorized removing the

## Hypothesis
A separate local model worker can answer free-form questions using attributed
retrieval while Nibli and the room remain responsive. Exact private room records
can travel through an export to one selected private peer without losing origin.
## Test
Pinned model hashes and real consecutive generations; prompt token budget,
reasoning filtering, stop and worker failure; browser journal/export/restore;
CLI preview without writes, atomic conflict validation, idempotent imports,
signed private outbox, verified remote commit receipt and later recall. Run both
repository gates, native room tests, Wasm and browser checks.
## Evidence
Append measured outputs, source commit and limitations to N8-evidence.json.
## Falsifier
Hidden reasoning displayed or stored; a generated sentence presented as an
engine verdict; loss of original text; a private room message routed to a public
peer; reporting upload success without verifying the remote contents.
## Anti-fake
Exercise the pinned 0.6B weights separately from UI mocks. Use isolated temporary
private stores and an HTTP peer fixture for import/sync/restore, not the user's
actual private repository for test messages.
