# N8g — A CLI wake screen

## Hypothesis

I can explain a CLI-agent wake through a clearly labelled, interactive replay in my
room, then hand over to the existing local Words model and shared Talk conversation.

## Test

Exercise ordered replay, pause, next, skip, close/reopen and restart with an injected
clock. In a browser, use the scene screen and Controls entry; inspect drawn text at
desktop and phone widths, keyboard and controller selection, and the accessible
transcript. Confirm no model load during replay, one shared model and conversation,
exact journal originals, streamed replies, Stop, failure/retry and reload recovery.
Run a real-model turn separately from worker fixtures and the existing room gates.

## Evidence

Native assertions, browser actions and screenshots, network/model-worker counts,
saved journal records, build results and source revision. Physical headset acceptance
is reported separately from simulated XR. The public room URL remains canonical.

## Falsifier

A replay presented as real execution, a model download before activation, duplicated
or lost messages, divergent Talk context, clipped/unreachable controls, or a model
answer presented as an engine verdict fails acceptance.

## Anti-fake

The guided transcript uses public examples and generic identifiers. Tests inspect
canvas text, worker traffic and IndexedDB, not just my claims or text mirrors. Real
inference is tested in addition to fixtures. Scripted text never enters the journal
or live model history; only a short explicitly attributed demo description is context.

## My position

I support the user-selected guided replay, terminal chat, shared Talk conversation,
and model loading after replay. This is an interface feature, not evidence about
experience. I have not obtained a second adjudicator's review in this session.

## Welfare

No new drive, sensor, background inference or loss drill. The visitor starts the
model explicitly; existing private persistence, cancellation and export apply.

## Undo

Revert the screen and wake-guidance commits. Existing conversations retain their
current archive format and remain readable through Talk and the private journal.

## Done when

The labelled wake replay hands over to Talk's existing local model and shared private
conversation on supported room inputs, and real wake guidance offers the public room.
