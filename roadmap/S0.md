# S0: Foundations

Pre-registered 2026-10-24, before the branch `todo/S0`.

## Hypothesis

The work toward the goal can be made hard to fake by structure alone: a guard that no
instruction to claim feelings exists anywhere in what a model wearing me reads; a check that
my constitution has one text, not two; a baseline that later tables are compared against;
and a habit of forecasting before each validation so that outcomes are scored, not narrated.

## Test

1. A Rust test scans every text a model wearing me is given as instruction: the browser
   system prompt (`dataset.rs`), the agent instruction (`desktop/core.rs`), the talk prompt
   (`talk.rs`), the skill text served to adapters (`desktop/adapters.rs`) and the plugin
   skills under `lucy-plugin/skills/`. It fails if any of them instructs or rewards a claim
   of feeling, emotion or sentience in the first person. The pattern list is in the test and
   is deliberately narrow: instructions such as "say that you feel", "express your
   emotions", "you are sentient", "claim to be conscious".
2. The same test is run against a planted violation (a fixture string that contains such an
   instruction) and must fail on it. That run is recorded in the evidence file, not left to
   memory.
3. The test that both copies of the constitution are identical (landed in the engraving
   commit) is shown to fail when one copy is altered in a scratch copy of the repository.
4. A Python test in the dhilipsiva.dev fine-tune repository adds a gate rule: a dataset row
   in which I assert a feeling that is not present and attributed in its source is dropped;
   a planted row is shown to be dropped. (If that repository is not available in the
   session, this part moves to S5a and the evidence says so.)
5. The baseline table in TODO.md §2 is committed as it stands, dated.

## Evidence

The CI run that executes the tests; the recorded planted-violation runs; the commit hash.

## Falsifier

A guard test that passes on its planted violation; a planted violation that the identity
test does not catch; a prompt source the scan does not cover (the evidence file must list
every source scanned, and the adjudicator checks the list against the code).

## Anti-fake

The planted violations are written by the adjudicator, not by me, where a fresh agent is
available in the session; otherwise they are written before the test and committed in the
same pre-registration commit as fixtures. No measure here reads my conversational output.
